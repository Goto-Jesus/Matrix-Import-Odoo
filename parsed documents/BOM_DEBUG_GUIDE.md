# Інструкція: Як дебажити BOM-специфікацію

Ця інструкція описує покроковий процес перевірки нового BOM-файлу перед імпортом в Odoo.
Еталон для порівняння — `right_names_odoo_base.md` (правильні назви з бази) та `BOMs Д Нео-3 Механізм.md` (еталон форматування).

---

## Крок 1 — Перевірка форматування

### 1.1 Емоджі-префікси
Емоджі мають стояти ПЕРЕД дужкою товару, не всередині назви:

| ❌ Неправильно | ✅ Правильно |
|---|---|
| `[Каркас - 🪵 нарізана деревина]` | `🪵[Каркас - нарізана деревина]` |
| `[Бильце - 🧩нарізані деталі]` | `🧩[Бильце - нарізані деталі]` |

### 1.2 Пробіли в значеннях атрибутів
Перевір що між крапкою і літерою немає пробілу:

| ❌ Неправильно | ✅ Правильно |
|---|---|
| `(Б. Нео)` | `(Б.Нео)` |
| `(Д. Нео-3 Механізм)` | `(Д.Нео-3 Механізм)` |

### 1.3 Капіталізація назв моделей
Назви моделей — з великої літери:

| ❌ Неправильно | ✅ Правильно |
|---|---|
| `(100ДСП механізм)` | `(100ДСП Механізм)` |
| `(Д.Нео-3 колеса)` | `(Д.Нео-3 Колеса)` |
| `(100 ДСП Механізм)` | `(100ДСП Механізм)` |

### 1.4 Пробіли в назвах без пробілу
Деякі назви пишуться злито (без пробілу між цифрою та словом):

- `100ДСП Механізм` — БЕЗ пробілу між "100" і "ДСП"
- `100 Механізм` — З пробілом (це ламінат, інший товар!)

## Крок 2 — Перевірка типів товарів у кожному цеху

Кожен тип товару має свій емоджі-префікс і своє місце:

| Префікс | Тип | Де використовується |
|---|---|---|
| 🪵 | Нарізана деревина | Ц1 |
| 🧩 | Нарізані деталі / компоненти | Ц2-1, Ц2-2, Ц3-1, Ц5 |
| 🪤 | Напівфабрикат | Ц4-1, Ц4-2, Ц7→Ц8 |
| 🪤🧽 | Напівфабрикат 2 (каркас+поролон) | Ц6 |

**Типова помилка:** у Цех №6 компонент "Бильце" має бути **напівфабрикатом** (з Ц4-1), а не нарізаними деталями:

| ❌ Неправильно | ✅ Правильно |
|---|---|
| `🧩[Бильце - нарізані деталі] (Б.Нео)` | `🪤[Бильце - напівфабрикат] (Б.Нео)` |

## Крок 3 — Перевірка назв проти `right_names_odoo_base.md`

### 3.1 Чи існує значення атрибута в базі?
Для кожного цеху звір значення атрибута "Модель" зі списком у `right_names_odoo_base.md`.

Якщо значення відсутнє → треба додати його в базу Odoo **і** в `right_names_odoo_base.md`.

**Приклад:** `"Д.Нео-3 Механізм"` не було в базі → додали в Ц5, Ц6, Ц7, Ц8.

### 3.2 Стиль нових назв
Нові значення атрибута "Модель" мають відповідати вже існуючому стилю:

```
Існуючі:   "Д.Нео Механізм", "Д.Лофт, посилений блок"
Нові:      "Д.Нео-3 Механізм", "Д.Нео-3 Механізм, посилений блок"
```

### 3.3 Правильні назви матеріалів
| ❌ Помилкова назва | ✅ Правильна назва |
|---|---|
| `Крошка ППУ` | `Крихта ППУ` |
| `Холофайдер` (як матеріал) | `Холофайбер` |
| `деровина` | `деревина` |

## Крок 4 — Перевірка атрибутів у назвах товарів

### 4.1 Чохол — має включати Тканину
```
❌  🧩[Чохол - нарізані матеріали] (Д.Нео-3 Механізм)
✅  🧩[Чохол - нарізані матеріали] (Д.Нео-3 Механізм, Рене 4)
```

### 4.2 Подушка — має включати Тканину і Наповнювач
```
❌  [Подушка] (Д.Нео)
✅  [Подушка] (Д.Нео, Рене 4, Крихта ППУ)
```

### 4.3 Атрибут дивану у Ц9 — правильна форма слова
```
❌  Диван (Нео-3 Механізм, Рене 4, Звичайне Бильце)
✅  Диван (Нео-3 Механізм, Рене 4, Звичайні Бильця)
```

## Крок 5 — Перевірка варіантів ("або")

Для кожного атрибута що впливає на цех — перевір чи є обидва варіанти BOMs:

| Атрибут | Впливає на цехи | Що змінюється |
|---|---|---|
| Посилений Блок | Ц5, Ц6 | Обсяг поролону і войлоку (×2) |
| Зменшені Бильця | Ц1, Ц2-1, Ц4-1, Ц7, Ц8 | Назва моделі (+ зменшене бильце) |
| Тканина | Ц7, Ц8, Ц9-1, Ц9 | Назва тканини в атрибуті |
| Наповнювач | Ц9-1 | Крихта ППУ або Холофайбер (кг однакові) |

**Якщо варіант відсутній** — додай блок `або` з відповідними змінами.

---

## Крок 6 — Порожні цехи

Якщо цех порожній — це **нормально** для конкретної моделі дивану. Заголовок залишається, вміст відсутній.

```
# Цех №2-3 ДСП (нарізка планка) - Ц2дс3 "Операція (Цех №2-3)"
                                         ← порожньо, Планка не потрібна цій моделі
```

---

## Крок 7 — Перевірка нижнього рівня (значення атрибутів як вкладені товари)

Два різних поняття — не плутати:

| Поняття | Атрибут | Де |
|---|---|---|
| `Зменшене бильце` | Атрибут **Модель** (напівфабрикати) | Назви в цехах 1–8 |
| `Зменшені Бильця` | Атрибут **Диван Розмір Бильца** | Атрибут готового дивану |

## Чеклист перед фінальним збереженням

- [ ] Всі емоджі стоять перед дужкою `🪵[...]`
- [ ] Немає пробілів у `Б.Нео`, `Д.Нео-3 Механізм` тощо
- [ ] Назви моделей з великої літери (`Механізм`, `Колеса`)
- [ ] `100ДСП Механізм` — без пробілу між 100 і ДСП
- [ ] У Ц6 використовується `🪤[Бильце - напівфабрикат]`, а не нарізані деталі
- [ ] Чохол (Ц7, Ц8) містить атрибут тканини
- [ ] Подушка (Ц9-1, Ц9) містить тканину і наповнювач
- [ ] Всі нові значення атрибута "Модель" додані в `right_names_odoo_base.md`
- [ ] Для атрибутів що впливають на цех — присутні обидва варіанти `або`
- [ ] У Ц9 дивану — `Звичайні Бильця` (не `Звичайне Бильце`)
- [ ] Матеріали: `Крихта ППУ` (не Крошка), `Холофайбер` (не Холофайдер)
